# Jobs panel dialog specs

These two panels are the source drawings for the Create Job dialog that phase 4 of the jobs panel plan builds from. They
were exported from the design canvas, so they reference a `support.js` runtime that is not committed here; read them as
markup for the exact labels, spacing and colours, or open them on the canvas to see them rendered.

- `Spec-Create-Job.dc.html` is the dialog opened from the Jobs page: job type, then variant, scope and settings.
- `Spec-Run-On-Capture-Set.dc.html` is the same dialog opened from a capture set, with the scope already chosen.

The copy in both panels is transcribed in `docs/claude/planning/2026-09-22-jobs-panel-dialog-build-spec.md`.
